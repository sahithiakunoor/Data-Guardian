Project Title:

DataGuardian: AI-Powered Data Quality and Anomaly Detection System

Problem Statement:

Data analysts often spend most of their time cleaning and validating datasets instead of generating insights. Manual data quality checks are inconsistent, slow, and error-prone, especially when datasets are large or frequently updated.

Project Summary (Portfolio-Ready Paragraph):

DataGuardian is an end-to-end AI system designed to assist data analysts by automating data quality checks and anomaly detection. Built with Flask, Python, and React, it allows users to upload datasets, automatically profiles data for missing values, outliers, and inconsistencies, and then uses machine learning to detect anomalies. A Large Language Model (LLM) layer interprets these findings and provides human-readable explanations and cleaning recommendations. The system integrates MLflow for workflow tracking, Docker for containerization, and AWS/GCP for deployment — showcasing a full-stack implementation of MLOps principles. Rather than replacing analysts, DataGuardian enhances their productivity and trust in data-driven decisions.
